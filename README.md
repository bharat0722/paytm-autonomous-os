# Paytm Autonomous OS

A browser-based Merchant Reliability OS prototype for a synthetic Soundbox incident. The demo shows how 24 simulated devices move from incident detection through partial recovery, an approval decision, and a recovery check.

[Open the live demo on Vercel](https://merchant-reliability-demo.vercel.app/)

## Run locally

Open [index.html](index.html) in a browser. The demo uses synthetic records and simulated device actions.

Select **Run Soundbox demo**. After 20 of 24 devices recover, approve the simulated restart to see all 24 recover, or reject it to see the incident escalate. **Reset demo** restores the example.
